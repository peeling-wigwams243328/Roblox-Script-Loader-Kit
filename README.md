## FAQ

### What is XCutors?

XCutors is a bundled collection of several well-known Roblox script executors for Windows, unified under a single universal loader for convenience.

### Which executors are included?

The package currently includes Volt, Synapse Z, Potassium, Wave, and the universal xcutorsLoader.

### What operating system do I need?

XCutors is designed exclusively for Windows 10 and Windows 11 (64-bit). It is not available for macOS or Linux.

### How do I update the executors?

The built-in auto-update feature in xcutorsLoader checks for new versions on launch. You can also manually trigger an update from the Settings menu.

### Can I use multiple executors at the same time?

It is recommended to use one executor at a time per Roblox instance. However, xcutorsLoader supports multi-instance setups if you want to run different executors on separate Roblox windows.

### Where can I find scripts to use?

XCutors includes a built-in script hub with curated scripts. You can also paste any Lua script from external sources into the editor.

### Is XCutors free to use?

XCutors is a free loader that aggregates existing executors. Some individual executors may have their own licensing or access requirements.

### I'm getting a Windows Defender warning. Is this normal?

Yes, many script executors trigger false positives because they interact with other running processes. You may need to whitelist the XCutors folder in your anticomponent settings.

### How do I switch between executors?

Open xcutorsLoader, return to the dashboard, and select a different executor. The loader will handle launching the new one for you.

### My executor crashes or won't attach. What should I do?

Make sure your Roblox client is up to date, run the executor as Administrator, and verify that your anticomponent is not blocking any of the executor files.
